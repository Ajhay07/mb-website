# MB Metallic Bellows website

Static site: HTML pages generated by `build/build.py`, styles in `css/style.css`, script in `js/main.js`.
Edit `build/build.py` and run `python build/build.py` (do not hand-edit the generated `.html`).
Light theme, Dassault Systèmes (3ds.com) blue/white as the visual reference, Barlow type kept.
Pill buttons and cards use soft shadows and rounded corners; hero/page-hero photos carry a dark
gradient scrim; circular accents replace the old gold hexagon motif. Keep the existing imagery,
typography and copy — only the chrome (color, shape, elevation) follows the reference.

## React Bits
`react-bits/` is a React + Vite + Tailwind + shadcn sidecar with the `@react-bits` registry configured.
The shadcn MCP server is set up in `.mcp.json` (needs a Claude Code restart to load).
When asked for an animation, hero, background, card, cursor or text effect, search React Bits first
(MCP tools `search_items_in_registries` / `view_items_in_registries`, registry `@react-bits`),
read the real source, install it into `react-bits/` with
`npx shadcn@latest add @react-bits/<Name>-<JS|TS>-<CSS|TW>`, restyle to match the site, and run
`npm run build` there. Use it only where it improves the page; never invent component names or props.
